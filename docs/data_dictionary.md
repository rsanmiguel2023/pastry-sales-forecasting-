# Data Dictionary

## Core raw fields
- `date`
- `store`
- `sales`
- weather variables
- holiday flags
- optional `unsold` / `ordered`

## Engineered fields
- `day_of_week`
- `month`
- `is_weekend`
- encoded holiday flags
- transformed variables
- `sales_lag_1`
- `sales_lag_7`
- `sales_rolling_mean_7`
- `sales_rolling_mean_14`
