# Streamlit Community Cloud Deployment

This repository is ready for Streamlit Community Cloud deployment.

## Entry point
`app/streamlit_app.py`

## Steps
1. Push this repository to GitHub
2. Sign in to Streamlit Community Cloud with GitHub
3. Choose this repository
4. Select the `main` branch
5. Set the main file path to `app/streamlit_app.py`
6. Deploy

## Notes
- Keep `requirements.txt` in the repository root
- If you add secrets later, configure them in Streamlit Community Cloud
- Any push to the selected branch can trigger an app update
